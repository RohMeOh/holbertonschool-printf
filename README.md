# Custom printf in C

**Holberton School · Software Engineering Coursework**

A custom implementation of formatted console output, organized into parsing, specifier-handling and helper functions.

## Technology and concepts

C, variadic arguments, format specifiers, string formatting and modular compilation.

## Exercises and files

| File | Description |
| --- | --- |
| [`_printf.c`](./_printf.c) | C source file for printf. |
| [`handle_specifier.c`](./handle_specifier.c) | C source file for handle specifier. |
| [`helpers.c`](./helpers.c) | C source file for helpers. |
| [`main.h`](./main.h) | C header with declarations and shared interfaces. |
| [`man_3_printf`](./man_3_printf) | Project file: man 3 printf. |

## Working with the exercises

Review the individual directory README files and exercise source before running or compiling them. Each task may have its own dependencies, test driver, or required inputs; do not assume every file is a standalone program.
